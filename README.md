# Експериментальний контроль зв’язку на iPhone
Це окремий нативний застосунок. На Windows вихідний код не компілювався: потрібна перевірка збіркою Xcode у хмарі або на Mac. Готового встановленого застосунку наразі немає.

## Поведінка
- Запити до HTTPS /healthz: у відкритій програмі щохвилини, тайм-аут 8 секунд.
- iOS отримує запит фонового запуску не раніше ніж через 15 хвилин. Це не гарантія періодичності.
- Успішна відповідь планує місцеве нагадування через 20 хвилин. Нове успішне підтвердження переносить його. Якщо iOS не запустила програму вчасно, нагадування можливе і при справному зв’язку. Текст не стверджує доведену аварію.
- Якщо реальна перевірка зазнала невдачі і відповіді немає понад хвилину — окреме сповіщення.
- Вимкнення контролю скасовує фонове завдання і нагадування. Для звуку потрібні дозволи та відповідні параметри iPhone.
- Немає критичних сповіщень, обходу беззвучного режиму, фонової музики або VPN.

## Збірка без власного Mac
1. У власному обліковому записі GitHub створіть окремий репозиторій лише для ВМІСТУ цієї папки. Не завантажуйте весь проєкт монітора, архів, settings.json, ключі або сертифікати.
2. Workflow .github/workflows/build.yml має бути в корені репозиторію. У вкладці Actions запустіть Build iPhone test.
3. Успішна збірка на хмарному macOS видасть артефакт BoilerLinkWatch-unsigned.ipa. Його потрібно підписати локально для iPhone; сам непідписаний IPA не встановлюється.
4. AltServer/AltStore Classic підтримує встановлення з Windows за офіційною інструкцією. Apple ID вводьте особисто в інструменті встановлення. Для безкоштовного підпису потрібне поновлення не рідше ніж раз на 7 днів. Сумісність з конкретним iPhone перевіряється під час встановлення.
5. При запиті iOS увімкніть Developer Mode і дозвольте сповіщення/фонове оновлення. Тестуйте спочатку вручну, потім із заблокованим екраном; окремо з інтернетом і без нього. Не вимикайте поточні робочі сповіщення.

Хмарна збірка, підпис, встановлення й поведінка на пристрої ще НЕ перевірені. Інтервали 15/20 хвилин є експериментальними.
